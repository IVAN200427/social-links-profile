# Social Links Profile

A simple, responsive profile card built with HTML and CSS. Features a dark theme, smooth hover effects on buttons, and custom typography using the Inter font from Google Fonts.

## Features

- Sleek dark UI
- Interactive button hover animations
- Mobile-friendly layout using Flexbox
- responsive for
- Mobile: 375px
- Desktop: 1440px

## How to View

Just clone or download the code, then open `index.html` in your web browser.
